# 摄影师风格属性参考库

> 本文件从 SKILL.md 拆分而出，仅在充实 style 字段时读取。

## 充实标准

`style` 字段根据摄影师特点灵活调整（通常 3-5 组），每组 3-4 个条目。

**质量门槛**：≥ 3 组 且 ≥ 8 项

**每个 item 结构**：
- `label`：简短标签（中文，4-8字）
- `desc`：补充说明（可选，括号内可加英文术语）

**photoStyles 字段**：4 个标签，从描述中提取关键词
**highlights 字段**：3-4 个亮点，突出摄影师特色和专长

## 充实流程

1. **阅读描述**：仔细阅读摄影师的英文 description、tagline、photoStyles
2. **理解定位**：理解这个摄影师的独特气质和差异化特点
3. **关键词匹配**：将描述与上述属性库的关键词逐一匹配
4. **分组生成**：每个类别中选取得分高的属性，按摄影师特点组织为 3-5 个分组
5. **保底机制**：确保至少 3 个分组、8 个 item；不足则补充通用的「整体调性」和「拍摄手法」
6. **质量检查**：最终 ≥ 3 组、≥ 8 项
