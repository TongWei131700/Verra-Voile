# 小红书自动搜索截图脚本 — 安装与使用指南

## 一、准备工作

### 1. 安装 AutoX.js

从 GitHub 下载最新版：
- 地址：https://github.com/kkevsekk1/AutoX/releases
- 下载 `inrt.xxxx.apk`（运行时版本）
- 安装到闲置 Android 手机

> 如果 GitHub 访问困难，也可以在酷安搜索「AutoX.js」下载

### 2. 配置手机权限

安装后需要授予以下权限：

| 权限 | 用途 | 设置路径 |
|------|------|---------|
| **无障碍服务** | 脚本核心能力，识别和操作 UI | 设置 → 无障碍 → AutoX.js → 开启 |
| **存储权限** | 保存截图到手机 | 设置 → 应用 → AutoX.js → 权限 → 存储 |
| **悬浮窗权限** | 显示运行状态浮窗 | 设置 → 应用 → AutoX.js → 权限 → 悬浮窗 |
| **后台运行** | 防止被系统杀掉 | 设置 → 电池 → AutoX.js → 不限制后台 |
| **自启动** | 可选，用于定时执行 | 设置 → 应用 → AutoX.js → 自启动 |

### 3. 准备小红书账号

- 安装小红书并**登录**（未登录看到的内容有限）
- 先正常使用 2-3 天（浏览、点赞），让账号看起来像正常用户
- **关闭**小红书的「省流量模式」

## 二、导入脚本

### 方式 1：USB 传输
1. 将 `xhs-auto-capture.js` 通过 USB 传到手机
2. 放到任意目录（如 `/sdcard/Scripts/`）
3. 打开 AutoX.js → 左上角菜单 → 导入 → 选择文件

### 方式 2：直接复制
1. 打开 AutoX.js
2. 点击右下角「+」→ 脚本
3. 将脚本内容全部粘贴进去
4. 保存，命名为 `xhs-auto-capture`

---

## 三、配置参数

打开脚本，修改顶部的 `CONFIG` 对象：

```javascript
const CONFIG = {
    // 搜索关键词 — 按需修改
    keywords: [
        "目的地婚礼",
        "三亚目的地婚礼",
        "大理目的地婚礼",
        "旅拍推荐",
    ],

    // 每个关键词滑动截图页数（越大截图越多，但也更容易被检测）
    scrollPages: 5,

    // 是否进入帖子详情截图
    enterPostDetail: true,

    // 每个关键词进入几个帖子
    postsPerKeyword: 3,

    // 截图保存路径
    savePath: "/sdcard/xhs_screenshots/",
};
```

### 参数建议

| 场景 | scrollPages | postsPerKeyword | 预计截图 | 预计耗时 |
|------|------------|----------------|---------|---------|
| 快速测试 | 2 | 1 | ~20 张 | ~5 分钟 |
| 日常采集 | 5 | 3 | ~60 张 | ~15 分钟 |
| 深度采集 | 10 | 5 | ~120 张 | ~30 分钟 |

> 建议不要一次跑太多关键词，每天 3-5 个关键词比较安全

---

## 四、运行脚本

1. 打开 AutoX.js
2. 找到 `xhs-auto-capture` 脚本
3. 点击运行（▶ 按钮）
4. 脚本会自动：
   - 启动小红书
   - 依次搜索每个关键词
   - 滑动浏览并截图
   - 进入帖子详情截图
   - 返回继续下一个

### 运行中注意

- **不要触碰手机屏幕**（会干扰脚本操作）
- 屏幕会保持亮起状态
- 可以最小化 AutoX.js，脚本在后台运行
- 如需中断：下拉通知栏 → 点击 AutoX.js → 停止

## 六、后续处理（截图 → 数据）

截图只是第一步，后续需要用 AI 提取结构化数据：

### 方案：用多模态大模型分析截图

将截图发给 Claude Vision / GPT-4o，Prompt 示例：

```
请分析这张小红书截图，提取以下信息：
1. 帖子标题
2. 提到的商家/品牌名称
3. 提到的目的地城市
4. 用户评价倾向（正面/负面/中性）
5. 互动数据（点赞、收藏、评论数）

以 JSON 格式返回。
```

## 七、常见问题

### Q: 脚本报错「找不到搜索框」
A: 小红书可能更新了 UI。用 AutoX.js 的「布局分析」功能查看当前界面的控件结构，然后修改脚本中的选择器。

### Q: 运行几次后被要求验证码
A: 说明触发了风控。建议：
- 增大操作间隔（调大 minDelay/maxDelay）
- 减少每天的运行次数
- 先正常使用小红书几天再跑脚本

### Q: 截图是空白的
A: 检查是否授予了存储权限。部分手机需要在「设置 → 隐私 → 截屏/录屏」中单独授权。

### Q: 小红书启动失败
A: 确认：
1. 小红书已安装且版本不是太旧
2. App 名称确实是「小红书」（有些修改过包名的版本可能识别不到）
3. 可以在脚本中改用包名启动：`app.launchPackage("com.xingin.xhs")`
